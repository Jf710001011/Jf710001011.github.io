Difference

  1. A forward proxy serves the client, helping it access external resources. A reverse proxy serves the server, helping it handle incoming requests securely and efficiently.

用户密码认证

🛠 1. 安装认证模块

Squid 使用 basic_ncsa_auth 来做用户名密码认证。

执行：

xxxxxxxxxx
2
1
sudo apt update
2
sudo apt install apache2-utils -y

（apache2-utils 里面包含了 htpasswd 工具）

🛠 2. 创建认证文件并添加账号

创建一个认证文件，比如：

xxxxxxxxxx
1
1
sudo htpasswd -c /etc/squid/passwd myuser

  • -c 表示新建文件（注意：以后新增用户不要加 -c，否则会覆盖掉）

  • myuser 是用户名，自定义

然后输入两次密码。

✅ 执行后 /etc/squid/passwd 文件就保存了用户名和加密后的密码。

如果你要添加更多用户（不要 -c）：

xxxxxxxxxx
1
1
sudo htpasswd /etc/squid/passwd anotheruser

🛠 3. 修改 squid.conf 配置认证逻辑

打开配置文件：

xxxxxxxxxx
1
1
sudo nano /etc/squid/squid.conf

在 http_port 3128 那块附近，加上以下内容：

xxxxxxxxxx
15
1
# 设置基本认证
2
auth_param basic program /usr/lib/squid/basic_ncsa_auth /etc/squid/passwd
3
auth_param basic realm ProxyServer
4


5
# 定义需要认证的 ACL
6
acl authenticated proxy_auth REQUIRED
7


8
# 允许认证通过的用户访问
9
http_access allow authenticated
10


11
# 拒绝其他所有
12
http_access deny all
13


14
# 监听端口
15
http_port 3128

🛠 4. 保存并重启 Squid

xxxxxxxxxx
1
1
sudo systemctl restart squid

🛠 5. 客户端连接测试

在客户端（如浏览器、curl）配置代理后：

  • 访问网页时会弹出一个输入框，要求填写：

    • 用户名

    • 密码

输入你刚刚设置的账号密码即可！

如果 curl 测试带认证参数：

xxxxxxxxxx
1
1
curl -x http://myuser:mypassword@你的服务器IP:3128 http://www.baidu.com
